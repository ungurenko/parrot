# Как отдавать Parrot пользователям

## Какой файл давать пользователю

Пользователю нужно давать файл установщика:

https://github.com/ungurenko/parrot/releases/download/v0.1.0/Parrot_0.1.0_aarch64.dmg

Это обычный установочный файл для macOS.

Пользователь скачивает `.dmg`, открывает его и переносит Parrot в папку Applications / «Программы».

## Что может увидеть пользователь при первом запуске

Parrot сейчас не подписан через Apple Developer, поэтому macOS может показать предупреждение:

- приложение скачано из интернета;
- приложение от неизвестного разработчика;
- macOS не может сразу открыть приложение.

Это нормально для приложения, которое распространяется не через App Store.

Обычно помогает открыть приложение через правый клик по Parrot → «Открыть».

Если macOS все равно блокирует запуск, нужно открыть:

System Settings / «Системные настройки» → Privacy & Security / «Конфиденциальность и безопасность»

и разрешить запуск Parrot вручную.

## Как будут работать обновления

После первой установки пользователь сможет обновлять Parrot внутри приложения.

Сценарий такой:

1. Пользователь установил Parrot `0.1.0`.
2. Потом выходит новая версия, например `0.1.1`.
3. Пользователь открывает настройки Parrot.
4. Нажимает «Проверить обновления».
5. Parrot видит новую версию.
6. Пользователь нажимает «Обновить до v0.1.1».
7. Приложение скачивает обновление, устанавливает его и перезапускается.

## Что важно помнить при выпуске новой версии

- Нельзя проверять обновление с версии `0.1.0` на такую же `0.1.0`: приложение не будет обновляться само на себя.
- Для проверки обновлений нужно выпустить версию выше, например `0.1.1`.
- В GitHub Releases должны быть загружены файлы:
  - `Parrot_0.1.1_aarch64.dmg`
  - `Parrot.app.tar.gz`
  - `Parrot.app.tar.gz.sig`
  - `latest.json`

## Коротко

Первый раз пользователь скачивает `.dmg`.

Дальше Parrot сможет подтягивать обновления сам через GitHub Releases.
