# Локальные модели конспекта

Parrot создаёт конспекты локально. Транскрипт остаётся на компьютере и не отправляется в облако.

## Модели

| Модель | ID в настройках | HF repo | Размер | Роль |
| --- | --- | --- | --- | --- |
| Qwen 3-4B Instruct | `qwen3-4b` | `mlx-community/Qwen3-4B-Instruct-2507-4bit` | ~2.3 ГБ | компактный запасной вариант |
| Gemma 4 E2B-it | `gemma4-e2b` | `mlx-community/gemma-4-e2b-it-4bit` | ~3.6 ГБ | быстрая модель по умолчанию |

## Окружение

Приложение само ставит локальный Python и MLX-пакеты в Application Support. Для разработки можно подготовить окружение командой:

```bash
tools/setup_qwen_mlx.sh
```

Обе модели работают через `mlx==0.31.2` и `mlx-lm==0.31.3`. Для Gemma отключён режим скрытого размышления, чтобы в конспект попадал только готовый ответ.

## Проверка

```bash
printf 'Короткий русский текст для проверки конспекта.' > /tmp/parrot-summary-probe.txt
tools/probe_summary_model.py --model qwen3-4b --transcript /tmp/parrot-summary-probe.txt
tools/probe_summary_model.py --model gemma4-e2b --transcript /tmp/parrot-summary-probe.txt
```

Обе команды должны вернуть `"ok": true`.

## Проверенное сравнение

Замер выполнен на iMac M5 с 16 ГБ памяти, с одинаковым промптом и лимитом 700 токенов:

| Размер расшифровки | Qwen | Gemma | Ускорение |
| --- | ---: | ---: | ---: |
| 9,7 КБ | 24,86 с | 14,06 с | 43,4% |
| 33 КБ | 27,67 с | 14,30 с | 48,3% |
| 86 КБ | 51,51 с | 16,78 с | 67,4% |

Среднее ускорение — 56,6%. В тёплом серверном режиме приложения Gemma заняла 11,20 с против 23,45 с у Qwen, то есть была быстрее на 52,2%. У обоих ответов проверены Markdown-структура и ключевые факты; Gemma выдала больше содержательного текста на всех трёх расшифровках.

После обновления до актуальной версии Gemma повторный холодный замер на русском тексте размером 17,4 КБ занял 16,68 с против 27,26 с у Qwen. Ускорение составило 38,8%; оба ответа сохранили структуру и факты исходника.

При изменении модели или MLX-пакетов повторите команды выше на трёх русских расшифровках разной длины. Gemma должна оставаться минимум на 20% быстрее, сохранять все обязательные разделы и не добавлять факты вне исходного текста.
