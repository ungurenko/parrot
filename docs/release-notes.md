## 🎯 Что нового

Parrot больше не оставляет несколько копий локальной модели конспекта после сбоя или принудительного завершения. Приложение переиспользует один warm server, при следующем запуске убирает только подтверждённые orphan-процессы Parrot и корректно завершает сервер при выходе. Это снижает расход памяти и swap на Mac с 16 ГБ и предотвращает тормоза.

## 📦 Как получить обновление

Откройте Parrot и установите обновление из появившегося уведомления. При чистой установке скачайте свежий DMG из GitHub Releases.
