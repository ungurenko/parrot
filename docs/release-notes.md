Релиз ускоряет путь транскрибации: Parrot быстрее готовит уже подходящие WAV-файлы и аккуратнее обрабатывает короткий финальный хвост в длинных записях Parakeet. Для готового 16 kHz mono WAV приложение пропускает лишнюю конвертацию через ffmpeg, а длинные записи меньше тратят время на ненужные короткие запуски модели.
