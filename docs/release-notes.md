Релиз обновляет загрузку с YouTube и чуть быстрее готовит уже готовые звуковые файлы. Если ролик раньше спотыкался на устаревшем загрузчике, теперь Parrot берёт свежую версию и реже уходит в долгий повтор. Аудио, которое уже в нужном формате, больше не копируется целиком — приложение просто переиспользует файл.

Распознавание Parakeet умеет идти ускоренным путём на чипе Apple, если на Маке уже есть локальное Python-окружение приложения. Если его нет, работает прежний стабильный путь — текст будет тот же.
