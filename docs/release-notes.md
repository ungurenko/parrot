## 🎯 Что нового

Экран обработки полностью обновлён. Источник, режим, язык, текущий статус, прогресс, следующие этапы и отмена теперь собраны в одной спокойной рабочей области — сразу видно, что происходит и сколько ещё ждать.

Вокруг попугая появился живой круг прогресса, а этапы «Аудио → Распознавание → Результат» связаны в понятный маршрут. На последних процентах Parrot честно сообщает, что заканчивает распознавание, а оценка времени больше не смешивает загрузку с обработкой речи.

Анимации во всём приложении стали мягче и выразительнее: аккуратно открываются настройки, меняются состояния конспекта и обновления, оживает история. Системная настройка уменьшения движения полностью соблюдается.

Для YouTube Parrot отдельно показывает момент использования сети. Само распознавание по-прежнему выполняется локально на Mac.

## 📦 Как получить обновление

Откройте Parrot и установите обновление из появившегося уведомления. При чистой установке скачайте свежий DMG из GitHub Releases.
