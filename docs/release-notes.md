## 🎯 Что нового

В настройках теперь можно скачать и выбрать любую совместимую модель одним понятным действием. Parrot сам устанавливает локальное окружение для Qwen3-ASR на macOS 14+, показывает ход подготовки и позволяет повторить загрузку после ошибки. Whisper расположен рядом с основным режимом и больше не теряется ниже скрытой области настроек.

Также Parrot точнее проверяет файлы моделей: повреждённая или незавершённая загрузка больше не считается готовой, поэтому кнопку скачивания можно использовать повторно.

## 📦 Как получить обновление

Откройте Parrot и установите обновление из появившегося уведомления. При чистой установке скачайте свежий DMG из GitHub Releases.
