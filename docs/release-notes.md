## 🎯 Что нового

Конспекты создаются минимум на 38% быстрее. Parrot теперь рекомендует Gemma 4 E2B-it и выбирает её по умолчанию для новых настроек: она сохраняет ключевые факты и структуру, но формирует подробный русский конспект заметно быстрее прежней модели.

Главный экран стал спокойнее и понятнее. Загрузку модели можно отменить, файл — открыть сочетанием ⌘O, а ошибки фоновых действий теперь сразу видны и объясняют, что делать дальше. Перед установкой обновления Parrot также показывает краткое описание изменений.

Локальные модели конспекта и распознавания используют совместимое окружение. Переключение между Gemma и Qwen больше не может повредить установку другой модели.

## 📦 Как получить обновление

Откройте Parrot и установите обновление из появившегося уведомления. При чистой установке скачайте свежий DMG из GitHub Releases.
