Релиз делает первый запуск и обычную работу спокойнее: Parrot теперь предлагает понятный быстрый старт, показывает режимы распознавания человеческими словами и мягче объясняет ошибки. После расшифровки появились быстрые действия — скопировать текст, открыть файл, собрать конспект или улучшить качество повторным запуском. История стала удобнее как архив: есть поиск, фильтры, группировка по датам и повтор новых задач.
