## 🎯 Что нового

Транскрибация стала заметно быстрее. Модель распознавания теперь постоянно живёт в памяти: файл или голосовая начинают обрабатываться сразу, без паузы на загрузку модели. Короткие голосовые превращаются в текст за доли секунды, длинные записи идут примерно в тридцать раз быстрее реального времени.

Parrot сам подстраивается под конкретный Mac: на машинах с 16 ГБ памяти и больше работает быстрый режим на видеокарте, на базовых моделях с 8 ГБ остаётся экономичный режим, который бережёт память и не грузит систему. Если быстрый режим вдруг дал сбой, задача автоматически продолжится на запасном — результат не теряется.

На длинных записях прогресс теперь двигается по ходу обработки, а не замирает на одном проценте.

## 📦 Как получить обновление

Откройте Parrot и установите обновление из появившегося уведомления. При чистой установке скачайте свежий DMG из GitHub Releases.
